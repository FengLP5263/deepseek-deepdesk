# DeepDesk 本地记忆

DeepDesk 的长期记忆保存在当前系统账号的 Electron `userData/deepdesk.json` 中。记忆不会写入项目目录，也不会因为用户说“记住”而创建 Markdown 或文本文件。

## 写入时机

每条用户消息发送前，客户端会在本地识别高置信度的长期信息：

- 明确要求记住、记录或保存到记忆的内容；
- 明确表达的长期偏好，例如“我喜欢……”“以后请……”“默认请……”；
- 姓名、称呼、职业等明确个人事实；
- 明确的项目决定和长期工程约定。

普通一次性任务不会自动保存。API Key、密码、Token、身份证和银行卡等敏感内容不会被自动捕获。相同内容会合并而不是重复创建。客户端升级后首次启动还会回扫已有本地聊天和 Agent 会话，补录其中符合上述规则的内容。

## 使用方式

发送请求前，客户端按当前问题检索相关的用户、项目和 Agent 记忆，并作为带明确边界的临时 system 上下文传给当前模型；每轮只保留本次命中的一份记忆，发送完成后不会写入原始会话历史。用户当前明确表达与旧记忆冲突时，以当前消息为准。

在“设置 → 记忆”中可以查看、编辑、停用、删除或手动新增记忆。当前版本采用保守的本地规则提取；相似语义合并和冲突提示仍属于后续能力。

## 默认工作目录

如果没有选择工作目录，Main 进程使用系统用户主目录作为 Agent 工作目录。Windows 通常为 `C:\Users\<用户名>`，macOS 通常为 `/Users/<用户名>`。界面中的“用户主目录”表示这一回退行为；选择目录后，会改用并持久化所选目录。
