# DeepDesk v0.44.0

Windows x64 预发布版本。本次汇总自 v0.42.0 以来的变更。

## 新增与调整

- 会话三点菜单改为归档；在“设置 → 归档”搜索、恢复，或二次确认后永久删除本地会话。归档保留历史、模型选择、置顶和待发送队列，并停止该会话正在运行的任务。
- MCP 支持选择 UTF-8 JSON 文件或粘贴内容导入。检查语法、字段类型、名称冲突和传输配置，预览确认后批量保存；不覆盖同名配置，导入后默认不连接、不执行命令。
- 会话正文与设置分离：独立 JSONL 增量日志、周期快照、轻量索引及运行中检查点；大型工具原文独立保存，可通过 `read_context` 分段读取。
- 兼容旧会话缺失 `history` 的情况，从已有对话和工具记录恢复上下文，避免客户端启动失败。
- 技能广场移除专家、连接器、SkillHub 和套件入口，保留精选、推荐、搜索、分类及安装管理，并改善缩放后的布局。

## 安装与升级

- 下载 `DeepDesk Setup 0.44.0.exe`，适用于 Windows x64。
- 升级前退出 DeepDesk，并备份完整的 Electron `userData` 数据目录。
- 首次升级会备份旧格式会话并迁移到 `sessions/`。旧版客户端无法读取新日志；降级需使用独立目录和迁移前备份，不能直接覆盖升级后的数据。
- 本次 Release 只附 Windows 安装包，不包含 macOS 安装包。
- 安装包尚未进行代码签名，Windows 可能显示未知发布者或 SmartScreen 提示；请核对下载来源及附件 SHA-256 校验值。

## 已知边界

- 永久删除不等于磁盘安全擦除，不会删除旧备份、导出文件、独立长期记忆、连接器活动或微信／飞书端消息。
- 连接器会话归档期间仍接收同步内容，但暂停自动回复；恢复后重新参与待回复检查。永久删除后，新消息会开启新的本地会话。
- MCP JSON 支持 `mcpServers` 或 `servers` 顶层对象以及 stdio / Streamable HTTP，不支持注释、尾随逗号、旧式 SSE、IDE 专属输入变量或未替换的占位符。
- 模型调用需要自行配置服务和凭据；不附带 API Key、用户会话或私有数据。

## 验证

- 296 项单元测试、67 项隔离 Electron E2E 已通过，覆盖归档恢复、永久删除、JSON 文件/粘贴导入及重启持久化。
- 已检查真实 Electron 的深浅主题和缩放截图；本机原生 Computer Use 通道不可用，采用项目规定的多状态截图复查。
